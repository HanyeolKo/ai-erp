# ai-erp-frontend-design

Read `harness/harness-spec.json` and enter through `ui-ux-designer` with `harness/skills/ai-erp-ui-ux/SKILL.md`.
Load `vendor/ux-skills/frontend-design/SKILL.md` only for relevant visual or frontend design work.
Treat the pinned skill as reference guidance within the user's scope and existing product conventions.
Use ERP task clarity, information density, visual hierarchy, accessible controls, and consistent states as concrete design constraints.
Preserve the current React/TypeScript stack unless the user requests a change; do not add a framework for stylistic reasons.
Record selected guidance and rationale in the local screen plan, then require independent `ui-plan-review` before implementing the screen.

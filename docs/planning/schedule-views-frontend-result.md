# 일정 작업공간 프론트엔드 결과

2026-09-21 기준, 구현 계약 r1과 API 계약 r2의 프론트엔드 범위를 반영했다.

- `/projects/:id/schedules`는 하나의 Shell 안에서 캘린더·카드·목록을 전환한다. 캘린더는 기존 월/주 그리드와 드래그·리사이즈·접근 가능한 대화상자를 재사용하되, 작업공간 쿼리와 저장 보기의 기간·필터를 사용한다.
- 개인/공유 보기 저장·복제·이름 변경·보관, 필터·그룹·범례·정렬·표시 필드 설정, 충돌 시 오류, 초안 닫기 확인을 제공한다. 필터 값은 숫자·체크박스·선택 옵션 ID·날짜/Instant로 타입을 유지한다.
- 속성은 생성·이름/순서 변경·보관 복구를 지원하고 단일 선택 옵션의 추가·라벨·색상·순서·보관을 편집한다. 상세/입력 화면은 보관된 값을 읽고 원자적 값 저장을 사용한다.
- 카드/목록은 실제 작업공간 쿼리 레코드와 페이지·그룹·범례를 표시하고 수정 링크는 관리자·작성자·취소되지 않은 일정으로 제한한다. 대시보드 선택은 PATCH로 저장한다.
- `scripts/ui-preview-server.mjs`와 `frontend/src/test/http.ts`에 브라우저/테스트용 synthetic W API 라우트를 추가했다.

검증: `pnpm frontend:typecheck` 통과, `node --check scripts/ui-preview-server.mjs` 통과, `pnpm frontend:build` 통과, 신규 작업공간 테스트 1개와 기존 캘린더/직접 조작 테스트 14개 통과. 전체 `frontend:test`는 기존 일정 화면의 레거시 필터·URL 기대가 새 작업공간 라우트와 달라 19개 실패했다. 부모가 브라우저 확인 전에 preview fixture 프로세스를 재시작해야 한다.

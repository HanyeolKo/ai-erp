## API shapes (backend worker implements; generated types authoritative)

- POST /projects body name, optional groupId, optional UUID requestId; existing Project response.
- /me adds displayName,email; Member response adds displayName,email (email may null for missing legacy profile). Fallback `이름 없는 구성원`, never rawUUID primary label.
- GET/POST /projects/{id}/share-invitation -> `{state:'NOT_CREATED'|'ACTIVE'|'EXPIRED'|'REVOKED',code:string|null,expiresAt:string|null}`; DELETE ->204.
- GET /project-invitations/{code} -> `{state:'ACTIVE'|'EXPIRED'|'REVOKED',projectId:string|null,projectName:string|null,inviterName:string|null,role:'MEMBER'|null,expiresAt:string,alreadyMember:boolean}`; nonactive metadata null. POST same/code/join ->Project.
- Read/mutate transport keeps credentials, CSRF and generation guards. Do not bypass with raw fetch in screen components.

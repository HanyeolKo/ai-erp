# Context budget

Read the entry contract and relevant role first; open only the vendor skill or references required for the current screen task.
Canonical instructions target 50 lines and have a hard maximum of 100 lines per document.
Do not paste full vendor guidance into project contracts or provider wrappers. Search UI/UX data for the current ERP users, task, and frontend stack.
Keep specialist inputs bounded to the relevant local plan, UI source, constraints, and acceptance criteria.
Keep reports concise, preserve raw evidence by reference, and expose checks not run.
Use at most four parallel tasks and two delegation levels. Inherit the current runtime model rather than choosing a vendor model.

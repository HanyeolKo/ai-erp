# Context budget

Read the entry contract and the relevant role before action.
Use the canonical limits `max_parallelism=2` and `max_delegation_depth=1` from `harness/harness-spec.json` and `.codex/config.toml`.
Open UI/UX references only for screen planning; open implementation references for contract tasks.
Canonical documents keep target 50 lines and hard limit 100 lines.
Keep specialist inputs bounded to local scope, constraints, and acceptance criteria.
Preserve raw evidence by reference and always expose checks not run.
Model defaults and escalation use `harness/policies/MODEL-ORCHESTRATION.md`; risk-tier verification and evidence reuse use `harness/policies/VERIFICATION.json`.

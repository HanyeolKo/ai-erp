# Model orchestration policy

The root orchestrator and final independent reviewer use `gpt-6-astra` with `high` reasoning. Native lower-role defaults are explicit: `router`, `product-planner`, and `ui-ux-designer` use `gpt-5.6-sol`/medium; `implementer` and `release-manager` use `gpt-5.6-luna`/high. The release-manager abstract tier is `fast`.

`gpt-5.3-codex-spark`/high is an explicitly selected high/complex implementation alternative. Its assignment and result record the selection reason, availability evidence, invocation/session evidence, context manifest and budget, output budget, fork/reuse choice, and provider usage availability. Bounded low/standard work records selected model/effort, reason, and brief evidence in `TASK-RECORD.md`; missing usage is `null` or `unavailable`, never zero.

Dispatch is bounded by `max_parallelism=2` and `max_delegation_depth=1`. Workers cannot spawn workers. High/complex generic dispatch supplies model, effort, canonical role/contract, bounded source manifest, context budget, and return budget; bounded low/standard dispatch may use the compact record. Parent-owned executor escalation follows `gpt-5.6-luna`/high -> `gpt-5.6-terra`/medium -> `gpt-5.6-sol`/medium; Astra is never an executor fallback and never Astra execution. A lower Sol role is at its ceiling and returns to the Astra orchestrator for self-review of assignment, decomposition, context, interfaces, prerequisites, and acceptance.

Record every escalation in `harness/templates/MODEL-ESCALATION.md`. It requires expected-versus-actual evidence, classification, prior attempts, parent authorization, exact scope, and validation. High-risk implementations, UI implementations after `ui-plan-review`, product plans, and release work retain their applicable independent review; low/standard implementation work follows `harness/policies/VERIFICATION.json` and may complete with parent acceptance. The ceiling is three total attempts including the initial attempt and escalation. External or quota blockers stop immediately, consume no retry attempt, and never justify a model sweep or Astra execution. Workers cannot self-escalate; missing capacity returns blocked unless the parent explicitly assigns an already-approved same-cost alternative.

Default to one active worker; use at most two only for explicitly disjoint useful work. New workers use `fork_turns=none` or minimal context; full-history fork requires parent justification. Reuse only the same bounded context, and use a fresh minimal assignment after scope/context changes. Do not rerun passed checks without a change or unresolved concern. Renaming a task or revision never resets attempts. Default returns target 250 words plus evidence paths.

Escalate only when a complete, clear contract has concrete evidence of a capability/comprehension failure. Clarify ambiguous or incomplete assignments; use a bounded same-model correction for an ordinary repairable defect; do not treat external prerequisites or capacity/quota as model incapability. Do not reset the attempt count by renaming a task or revision, and do not repeat unchanged work.

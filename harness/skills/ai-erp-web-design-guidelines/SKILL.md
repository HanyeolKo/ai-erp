# ai-erp-web-design-guidelines

Read `harness/harness-spec.json` and enter through `ui-ux-designer` with `harness/skills/ai-erp-ui-ux/SKILL.md`.
Load `vendor/ux-skills/web-design-guidelines/SKILL.md` and `vendor/ux-skills/web-design-guidelines/references/web-interface-guidelines/command.md` only for the current screen or review.
Prefer the pinned local guideline snapshot for reproducible review. A user-requested upstream refresh is a separate vendor update with provenance and hash checks.
Review semantic structure, keyboard access, focus, labels, forms, feedback, motion, responsive behavior, and loading/error/empty states against actual screen evidence.
For implemented UI, cite concrete file/line or browser evidence; for a plan, identify acceptance criteria and label implementation checks as not run.
Return findings with user impact to independent evaluator `ui-plan-review`. Do not claim visual, browser, or accessibility validation that was not performed.
